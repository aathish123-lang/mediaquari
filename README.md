# 🌐 Responsive Flexbox Layout

## 📌 Project Description
This project is created using **HTML and CSS**. It contains three content boxes arranged in a row using CSS Flexbox. Media Queries are used to make the layout responsive for different screen sizes.

## 🛠️ Technologies Used
- 🌐 HTML5
- 🎨 CSS3
- 📦 CSS Flexbox
- 📱 CSS Media Queries

## ✨ Features
- 📌 Three content boxes arranged horizontally on large screens.
- ↔️ Uses `display: flex` to arrange the boxes.
- 📏 Uses `gap` to maintain spacing between boxes.
- 🎯 Uses `justify-content: center` for alignment.
- 📱 Changes the layout from row to column on smaller screens.
- 📐 Adjusts box width based on screen size.

## 📱 Responsive Design

### 💻 Desktop View
- All three boxes are displayed in a row.
- Each box has a height of 180px.

### 📲 Tablet View (Max-width: 611px)
- Boxes are arranged vertically.
- Each box takes 75% width.
- Boxes are aligned to the center.

### 📱 Mobile View (Max-width: 401px)
- Boxes are arranged vertically.
- Each box takes 100% width.
